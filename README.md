# FiberGuard

تطبيق أندرويد لإدارة مودم الفايبر وحماية الشبكة المنزلية: حالة الاتصال، إشارة الفايبر، الأجهزة المتصلة، الحظر وأوقات الاتصال، الواي فاي، واختبار السرعة.

## التنزيل

نزّل ملف `FiberGuard-x.x.apk` من [آخر إصدار](https://github.com/shedokhe733-ui/FiberGuard/releases/latest) وثبّته على جوالك.

## المودمات المدعومة

- **Huawei فايبر** (HG8145X6، HG8245H، EG8145…): مدعومة بالكامل.
- **ZTE فايبر**، **TP-Link**، وراوترات **5G/4G** من Huawei وZTE (STC، زين، موبايلي): دعم تجريبي للمراقبة.
- مودمك غير مدعوم؟ من شاشة الدخول اضغط «أرسل تقرير التوافق».
